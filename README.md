# PathWeaver 🌐

**Weave Your Future, One Choice at a Time**

An interactive multimedia life journey simulator where users create a virtual character, progress through life stages, make decisions, and experience AI-powered consequences.

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18 + Vite + Tailwind CSS |
| Backend | Node.js + Express.js |
| Database | MongoDB Atlas + Mongoose |
| AI | OpenAI GPT-4 + DALL-E |
| Auth | JWT + bcryptjs |

## 📁 Project Structure

```
PathWeaver/
├── client/          # React frontend
├── server/          # Express backend
├── .gitignore
└── README.md
```

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- MongoDB Atlas account
- OpenAI API key

### Installation

```bash
# Install server dependencies
cd server && npm install

# Install client dependencies
cd ../client && npm install
```

### Environment Setup

```bash
# Copy the example env file
cp server/.env.example server/.env
# Edit server/.env with your API keys
```
